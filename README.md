# MEME ARENA — стартовый прототип

## Запуск
Открой `index.html` в браузере или опубликуй папку на статическом хостинге.

## Что уже работает
- адаптивная тёмная главная страница;
- демо-вход по нику;
- публикация мема по URL изображения;
- фильтр категорий и сортировка;
- голосование (один голос на мем с одного демо-профиля);
- таблица лидеров;
- сохранение данных в localStorage браузера.

## Важно
Это фронтенд-прототип. Демо-вход не является настоящей безопасной авторизацией: данные хранятся только в браузере и могут быть изменены пользователем. Голосование не защищено от накрутки, а опубликованные мемы не синхронизируются между устройствами.

## Следующий этап для публичного запуска
Подключить Supabase: Auth, таблицы profiles/memes/votes, Storage для картинок, Row Level Security и серверные проверки голосов. Добавить жалобы, модерацию, лимиты загрузки и правила сообщества. Не размещать реальные персональные данные в демо-версии.
